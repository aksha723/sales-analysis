# Sales Analysis Project

## Description
This project analyzes sales data of different products and generates key insights, such as total quantity sold and revenue generated for each product. The analysis is performed using Python, with data stored in an SQLite database.

The project includes:
- A Python script (`sales_analysis.py`) that connects to an SQLite database, processes sales data, and generates a bar chart visualizing the revenue for each product.
- Sample data of sales transactions (products, quantities, and prices) inserted into the database.
- A simple and clear bar chart to compare the revenue generated by each product.

The goal of this project is to provide a basic understanding of data analysis, visualization, and database handling using Python.

## Features:
- **Data Storage**: Sales data is stored and managed in an SQLite database.
- **Data Analysis**: The total quantity sold and total revenue for each product is calculated.
- **Visualization**: A bar chart is generated to visualize the revenue by product.

## Files:
- `sales_data.db`: SQLite database file containing sales data.
 'screenshort' data visuallization

## Requirements:
- Python 3.x
- pandas
- matplotlib
- SQLite3 (comes pre-installed with Python)

## How to Run:
1. Clone the repository: `git clone https://github.com/your-username/sales-analysis-project.git`
2. Install required Python packages: `pip install pandas matplotlib`
3. Run the script: `python sales_analysis.py`

This project serves as a basic template for analyzing sales data and visualizing the results using Python.
